# Sky Haven

Engineering platform for the Sky Haven organisation — cloud infrastructure,
products, and the shared standards that keep them consistent.

## Engineering standards

- **[Repository naming standard](https://github.com/skyhaven-ltd/.github/blob/main/standards/repo-naming.md)**
  — the canonical convention for naming every repository in the organisation,
  with a machine-readable spec enforced at repository creation.

## Conventions

Repositories are provisioned as code in
[`infra-github-platform`](https://github.com/skyhaven-ltd/infra-github-platform),
which applies the shared branch-protection ruleset and enforces the naming
standard above. Issue and pull-request templates in this repository are
inherited by every repository that does not define its own.
